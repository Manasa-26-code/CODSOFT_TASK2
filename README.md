# Task 2 - Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis on the Titanic dataset using Python.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset

The Titanic dataset contains information about 891 passengers and 12 columns.

## EDA Performed

- Dataset shape and column analysis
- Data types inspection
- Missing value analysis
- Duplicate row checking
- Statistical summary
- Survival count analysis
- Survival by gender
- Survival by passenger class
- Age distribution
- Fare distribution

## Key Findings

- Overall survival rate was approximately 38.38%.
- Female passengers had a survival rate of 74.20%.
- Male passengers had a survival rate of 18.89%.
- 1st-class passengers had a survival rate of 62.96%.
- 2nd-class passengers had a survival rate of 47.28%.
- 3rd-class passengers had a survival rate of 24.24%.

## Conclusion
